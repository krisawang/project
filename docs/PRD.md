## 核心需求（Must / Should / Could）

### Must
- [ ] 明确价值主张 + 主要 CTA
- [ ] 关键功能/优势展示（3-6 项）
- [ ] 社会证明（Logo/评价/案例）
- [ ] 价格或咨询路径
- [ ] 联系表单/预约入口
- [ ] 基础 SEO（metadata、sitemap、robots）

### Should
- [ ] Use Cases/场景说明
- [ ] FAQ
- [ ] 多语言或多地区版本
- [ ] 数据采集埋点（GA/Meta Pixel）

### Could
- [ ] 视频/动效模块
- [ ] 客户案例详情页
- [ ] Newsletter 订阅

## 验收清单
- [ ] 首页模块完整且视觉一致
- [ ] 移动端适配通过（至少 3 个断点）
- [ ] 表单可提交并提示成功/失败
- [ ] SEO metadata/robots/sitemap 可访问
- [ ] 性能指标满足基线（LCP < 2.5s、CLS < 0.1）
- [ ] 文案/品牌元素与客户一致

## 交付物清单
- [ ] 可部署的代码仓库
- [ ] 文案与媒体素材（图片、Logo、品牌色）
- [ ] 部署说明文档
- [ ] 可复用组件清单
- [ ] 上线后验收报告
